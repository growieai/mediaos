## First listening session

1. Open [ElevenLabs' Castilian samples](https://elevenlabs.io/text-to-speech/spanish-castilian-accent).
   **Sara Martin — Gentle and Layered** is listed there as Spanish Castilian and is a useful first
   audition candidate. Its listing has been verified; its sound has not yet been auditioned in this project.
2. In ElevenLabs, open **Voices → Explore**. Filter **Spanish**, **Spanish Castilian/Spain**,
   **Female**, and **Conversational**; also inspect **Social Media** voices. Prefer the Studio
   Quality filter and an available removal-notice period. Listen to three existing previews.
   [Official library guide](https://elevenlabs.io/docs/eleven-creative/voices/voice-library).
3. Shortlist the clearest conversational voice, a slightly more energetic voice, and a calmer
   one. Then compare the same short text below, with identical model settings. Generation uses
   account credits; do this only after the test spending limit is agreed.
4. Start the comparison with **Multilingual v2**, then try v3 with the winning voice if more
   expressive delivery is needed. This is an audition plan: the best result depends on the
   actual voice and text. [Official synthesis guide](https://elevenlabs.io/docs/eleven-creative/playground/text-to-speech).
